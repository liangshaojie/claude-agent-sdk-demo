# 任务规划技能

这个技能帮助用户将复杂的目标分解为可执行的任务列表。

## 使用场景

- 项目规划
- 学习计划制定
- 日常任务管理
- 目标分解

## 功能

1. **任务分解**：将大目标分解为小任务
2. **优先级排序**：根据重要性和紧急性排序
3. **时间估算**：为每个任务估算所需时间
4. **依赖关系**：识别任务之间的依赖关系

## 输出格式

返回结构化的任务列表，包含：
- 任务名称
- 优先级（高/中/低）
- 预估时间
- 依赖任务
- 具体步骤

## 示例

输入：我想学习 TypeScript

输出：
1. **了解基础概念**（优先级：高，时间：2小时）
   - 学习 TypeScript 是什么
   - 了解与 JavaScript 的区别
   
2. **环境搭建**（优先级：高，时间：1小时）
   - 安装 Node.js 和 npm
   - 安装 TypeScript 编译器
   - 配置 tsconfig.json

3. **基础语法学习**（优先级：高，时间：4小时）
   - 类型注解
   - 接口和类型别名
   - 函数类型
