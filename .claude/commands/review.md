## Context

项目结构：
- !`find . -name "*.ts" -o -name "*.js" -o -name "*.py" 2>/dev/null | head -20`

## Task

执行全面的代码审查，关注以下方面：

1. **代码可读性**
   - 变量和函数命名是否清晰
   - 是否有适当的注释
   - 代码结构是否清晰

2. **错误处理**
   - 是否有 try-catch 块
   - 错误是否被正确处理
   - 是否有未处理的 Promise rejection

3. **性能问题**
   - 是否有明显的性能瓶颈
   - 是否有内存泄漏风险
   - 是否有不必要的重复计算

4. **安全漏洞**
   - 是否有硬编码的敏感信息
   - 是否有 SQL 注入风险
   - 是否有 XSS 风险

5. **最佳实践**
   - 是否遵循该语言的编码规范
   - 是否有适当的测试
   - 是否有文档
